# Teahouse icons

Tea bowl, variant A (even gap between body and foot). Everything here is generated by `build_icons.py`. The copies the apps use live in `packages/app/src-tauri/icons/` and `packages/client/public/`, so update those after regenerating. To change a color or the geometry, edit the script and run it again (`pip install cairosvg resvg-py pillow`, then `python3 build_icons.py`).

| Folder | What it is | Use it for |
|---|---|---|
| `svg/teahouse-icon.svg` | Bowl on a rounded cream tile | Master app icon, docs, README badge |
| `svg/teahouse-icon-small.svg` | Larger bowl, tighter tile | Anything shown at 32 px or smaller |
| `svg/teahouse-icon-fullbleed.svg` | Square cream background, no rounding | Platforms that apply their own mask |
| `svg/teahouse-icon-transparent.svg` | Bowl only, square canvas | In-app logo on light surfaces |
| `svg/teahouse-icon-monochrome.svg` | Single-color silhouette (white) | Tray/menu-bar icons, themed icons; recolor with `fill` |
| `svg/teahouse-mark.svg` | Bowl only, tight 212×182 viewBox | Inline in UI, next to the wordmark |
| `png/with-bg/`, `png/transparent/` | 16–1024 px | General use; 16–32 px use the small-tile variant |
| `web/` | favicon.ico (16/32/48), favicon.svg, apple-touch-icon, PWA icons | Copy into the web app's `public/` |
| `ios/` | 1024 px opaque AppIcon + `Contents.json` | Contents of `AppIcon.appiconset` |
| `android/res/` | Legacy, round and adaptive icons (incl. monochrome for Android 13+) | Merge into `app/src/main/res/` |
| `android/play-store-512.png` | 512 px opaque | Play Store listing |
| `desktop/` | `teahouse.ico`, `teahouse.icns`, Linux hicolor sizes | Windows / macOS / Linux bundles |

## Web

```html
<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.webmanifest">
```

Merge `web/manifest-icons.json` into your web manifest.

## Notes

- The transparent versions have little contrast on dark backgrounds (dark green on dark gray). Use the tile versions wherever the background isn't known.
- Android adaptive foreground and the maskable PWA icon are checked against their safe zones (bowl radius 0.30 of 0.306, and 0.36 of 0.40).
- Colors: green `#0F3A2E`, rim `#1A4D3D`, gold `#D4AF62`, tea `#E3E9C6`, tile `#F4ECD8`.
